# 七巧板

一个可以在浏览器里玩的七巧板。七块板、十六个影子，鼠标和触摸都能拖、转、翻。

## 本地运行

```bash
npm install
npm run dev
```

然后打开 [http://127.0.0.1:4731](http://127.0.0.1:4731)。

打包成静态站点：

```bash
npm run build
npm run preview
```

`dist/` 可以直接放到任意静态服务器上。

核对十六关的拼法是否严丝合缝（面积、相连、不重叠，并且能触发胜利判定）：

```bash
npm run verify
```

## 怎么玩

选一关，把七块板铺满左边的影子。块与块之间不要叠在一起，盖满就算拼好了。

- 拖动板子。松手时，靠近正确位置或靠齐顶点会吸过去。
- 旋转每次 45°：点「左转 / 右转」，或双击（双触）板子，也可以拖板子上方的「转」。
- 只有平行四边形可以翻面：先选中它，再点「翻转」或「翻」，也可以按 `F`。
- 「提示」会用虚线标出一块还没放对的板。「撤销」退回上一步，「重置」把板子收回托盘。
- 「自由拼摆」没有影子，可以随便摆。

键盘：`Q` 左转，`E` / `R` 右转，`F` 翻面，`H` 提示，`Ctrl` / `⌘` + `Z` 撤销，方向键微调（按住 Shift 步子更大），`Esc` 取消选择。

计时从第一次真正移动开始，拼好后停止。步数和用时会记在这台浏览器里，更好的成绩会留下来。

## 关卡

入门：房子、蜡烛、箭头、小鱼、小猫、帆船、红心、鲸鱼。

进阶：方块、飞鸟、兔子、天鹅、乌龟、火箭、松树。

挑战：跑步的人。

每关都用齐七块板：两块大三角、一块中三角、两块小三角、一块正方形、一块平行四边形。比例是经典七巧板（两块大三角拼起来就是整副板的一半）。
